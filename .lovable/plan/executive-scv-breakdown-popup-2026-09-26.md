# Executive SCV breakdown popup

## Changes
- Replace the expandable table row with a popup opened by clicking an executive’s name.
- Show the existing component percentages, points, details, final SCV, slab, payout, and estimated incentive inside the popup.
- Reuse the currently selected Auto or Manual mode and month data without changing calculations.

## Scope
- Change only the SCV & Incentives page presentation.
- Keep all calculations, configuration, permissions, filters, and other pages unchanged.
